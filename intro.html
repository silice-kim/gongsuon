App Introduction

공수 기록부터 정산, 백업까지

일하는 사람의 마음에 딱 맞춘 시원시원한 공수 기록 애플리케이션.
실제 현장 스크린샷과 함께 공수 On의 핵심 기능을 빠르게 확인해 보세요.

큰글씨 달력 간편 공수입력 실수령 정산 엑셀 파일공유 클라우드 백업 든든한 지원
1. 큰글씨 달력

광고 없이 넓고 깨끗한
한눈에 들어오는 큰 글씨 달력

작업 중에 계속해서 튀어나오는 전면 광고 때문에 불편하고 지치지 않으셨나요? 공수 On은 현장 일에만 집중할 수 있도록 평생 광고 없는 환경을 약속합니다. 큰 글씨와 시원시원한 달력 화면으로 하루 일당과 메모 기록을 직관적으로 모니터링할 수 있습니다.

  • 평생 100% 광고 없음: 불필요한 배너나 전면 광고를 완벽 차단
  • 대시보드식 정보: 당월 근무일과 정산 예상 금액을 달력 내에 즉시 표시
  • 현장 중심의 높은 가독성: 침침함 없이 한눈에 식별 가능한 큼직한 화면 구성
2. 원터치 공수입력

바쁜 퇴근 시간도 걱정 없는
1초 완성 원터치 공수 기록

현장에서 일하느라 피곤하고 바쁜데 입력이 어려우면 안 되겠죠? 공수 On은 간결화된 원터치 버튼으로 퇴근길 단 1초 만에 공수를 입력합니다. 복잡한 단계 없이 달력의 날짜를 누르고 퀵 버튼만 선택하면 입력이 끝납니다.

  • 원클릭 퀵 입력: 0.5공수, 1공수, 1.5공수, 휴무 등 원터치로 빠르게 기록
  • 현장별 단가 관리: 현장별로 다른 일당 단가를 지정해 등록 시 수당 자동 산정
  • 스마트 세부 메모: 일당 외에 특별 일수, 잔업 기록 등 다양한 내용 보조 기입
3. 실수령액 정산

현장별 세금 계산까지 완벽!
스마트한 실수령액 자동 정산

일당 총액과 실제 통장에 꽂히는 금액이 달라 계산에 애를 먹은 적 있으시죠? 소득세 3.3%, 지방세, 고용보험 등 현장별 세금 및 4대보험 공제율을 소수점 자리까지 투명하게 공제해 정확한 실수령액을 보여줍니다.

  • 실시간 공제 계산: 일용직, 상용직 등 근로 형태에 따른 공제율 자동 계산
  • 현장별 맞춤 설정: 현장 등록 시 공제 옵션을 한 번만 셋팅하면 평생 자동 정산
  • 미수금 관리: 정산이 완료된 일급과 아직 받지 못한 미수금을 일목요연하게 표시

오늘 공수 기록부터 광고 없이 쾌적하게 시작하세요

이미 수많은 현장 선배 반장님들이 검증한 대한민국 대표 큰글씨 공수장부

4. 엑셀 파일공유

카카오톡으로 즉시 전송!
공수 내역 엑셀 파일 공유

수첩에 적어둔 공수를 일일이 받아 적거나 카메라로 찍어 사무실에 보내는 복잡함은 이제 그만하세요. 공수 On은 클릭 한 번에 깔끔한 표 양식의 엑셀 문서로 변환하여 카카오톡이나 문자, 이메일로 바로 전송할 수 있습니다.

  • 기간별/현장별 필터링: 원하는 정산 범위만 선택해 맞춤형 엑셀 파일 생성
  • 간편 클립보드 복사: 카톡 텍스트 형식으로도 복사하여 빠른 전송 지원
  • 투명한 정산 보고: 엑셀 데이터를 출력해 증빙 자료나 영수증으로 활용 가능
5. 클라우드 백업

스마트폰 변경 시에도 안전하게!
클라우드 백업 및 설정 이사

스마트폰을 고장으로 잃어버리거나 다른 최신 폰으로 변경해도 기존 기록 유실 염려가 전혀 없습니다. 간편한 구글 연동으로 데이터를 클라우드 서버에 암호화하여 보존하며, 기존 타 앱의 공수 데이터 가져오기도 완벽 연동됩니다.

  • 안전한 클라우드 동기화: 연동 시 실시간 혹은 1초 만에 안전한 백업 파일 생성
  • 기존 데이터 이사: 다른 공수 앱 데이터를 그대로 가지고 와 연속 기입 지원
  • 계정 일괄 연동: 폰 분실 시에도 로그인만 하면 전 근무 이력이 100% 복구

든든한 동반자가 되어 드립니다
