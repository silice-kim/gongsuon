공수 On 사용 가이드

터치 몇 번으로 간단하게 일당을 정산하고, 안전하게 기록을 보관하는 핵심 사용법을 알려드립니다.

STEP 01

오늘 날짜 탭하고
터치 한 번으로 빠르게 입력

공수 On은 앱 실행 시 바로 공수달력 화면이 나타납니다. 불필요한 단계를 거치지 않고 현장 퇴근 시 바로 기록할 수 있습니다.

  • 기록할 날짜를 달력에서 가볍게 탭합니다.
  • 하단에 나타나는 0.5공수, 1공수, 1.5공수, 2공수 중 선택합니다.
  • 터치와 동시에 달력에 즉시 반영되어 하루 기록이 1초 만에 완료됩니다.
STEP 02

실수령액 및
세금·공제 정산 명세서 자동 계산

일당 단가에 따른 총 급여는 물론, 소득세 3.3%나 4대 보험 등 공제 내역을 반영하여 내가 이번 달에 실제로 받게 될 실수령액을 오차 없이 자동으로 계산해 줍니다.

  • [정산 명세서] 메뉴에서 이번 달 총 공수와 세전 일당 합계를 한눈에 확인합니다.
  • 소득세 3.3% 공제 적용, 4대 보험 여부 등 각 현장 계약 조건에 맞는 세금 설정을 선택합니다.
  • 공제 세금과 보험료가 실시간 계산되어 자동 차감된 최종 실수령액(예상 수령액)을 즉시 산출해 줍니다.
꿀팁: 완성된 정산 내역은 터치 한 번으로 상세 명세서를 확인하고, 필요 시 엑셀 파일로 내보내어 안전하게 공유하거나 보관할 수 있습니다.
STEP 03

안전한 클라우드 백업 및
타 앱에서 쓰던 데이터 이사하기

기기를 변경하거나 폰을 분실하더라도 소중한 기록은 절대 사라지지 않습니다. 타 공수 앱에서 쓰던 데이터도 손쉽게 가져와 계속 기록할 수 있습니다.

  • 간편 로그인을 통해 소중한 근무 기록을 클라우드에 백업해 둡니다.
  • 휴대폰을 바꿨을 때 동일한 계정으로 로그인한 뒤 [데이터 불러오기]를 탭하면 원래의 데이터가 고스란히 복구됩니다.
  • [데이터 가져오기]를 활용하여 기존 다른 공수앱의 누적 데이터를 손실 없이 안전하게 가져옵니다.
STEP 04

기본값 설정으로
반복되는 입력 시간 단축

일당·공수 관련 자주 사용하는 값을 미리 설정해두면 입력 시 자동으로 적용되어 빠르고 편리합니다.

  • 일당 관련 기본값 설정: 자주 사용하는 기본 일당 금액과 증감값을 미리 설정하여 관리합니다.
  • 공수 관련 기본값 설정: 기준이 되는 기본 공수 및 증감값을 지정하여 빠른 정산을 돕습니다.
  • 자동 적용 편리함: 설정해 둔 기본값들이 작업 입력 화면에 실시간으로 반영되어 입력을 한 번에 완료합니다.
STEP 05

퀵 버튼 설정으로
한 번의 터치로 빠르게 입력

자주 사용하는 공수 값을 5개의 버튼에 등록해두고, 필요한 값을 빠르게 선택하여 입력할 수 있는 편리한 기능입니다.

  • 자주 쓰는 공수 값 5개 등록: 버튼별로 자주 사용하는 소수점 공수 값을 마음대로 커스텀 설정해 둡니다.
  • 한 번의 터치로 빠른 입력: 매번 번거롭게 숫자를 칠 필요 없이 버튼 하나 터치로 즉시 완료됩니다.
  • 입력 화면 즉시 반영: 퀵 버튼으로 입력한 정보는 캘린더 및 월말 정산에 자동 합산됩니다.
